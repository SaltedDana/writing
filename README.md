# Salted Mind — Writing

Essays on AI, strategy, and human intelligence — leadership, motivation, and the reasoning that doesn't automate away. By Dana Maman, founder of [Salted Mind](https://saltedmind.co).

## Featured

**[Taste isn’t the moat. You’re guarding the wrong thing.](taste-isnt-the-moat-youre-guarding/README.md)** — Taste judges what got made; sense decides what is worth making. Taste says fix the spacing on the landing page — sense says you do not need a landing page, you need a WhatsApp message to twelve people.
